# Catálogo de Formatos de Contenido
*40 formatos para transformar un guion núcleo*

---

## FORMATOS NARRATIVOS

### 1️⃣ Historia Curiosa / Biografía
**Objetivo:** Enseñar a través de storytelling real
**Energía:** Media verbal / Media visual | **Producción:** Media | **Retención:** Narrativa progresiva
**Estructura:** Contexto → Conflicto → Punto de quiebre → Resultado → Reflexión aplicable
**Gancho:** "¿Sabías que…?" / "Esta persona hizo algo que…"
**Ideal para:** Inspirar, educar, construir autoridad narrativa

### 4️⃣ B-Roll Storytelling
**Objetivo:** Narrativa visual dominante (sin hablar a cámara)
**Energía:** Media | **Producción:** Media-Alta | **B-roll:** Muy alto
**Estructura:** Voz en off → Clips ilustrativos → Final emocional
**Gancho:** Imagen intrigante mientras hablas
**Ideal para:** Storytelling emocional o reflexivo

### 8️⃣ POV
**Objetivo:** Inmersión e identificación directa
**Energía:** Variable | **Producción:** Baja | **Retención:** Identificación inmediata
**Estructura:** "POV: [situación]" → Desarrollo → Reacción/resolución
**Gancho:** "POV: …"
**Ideal para:** Empatía, viralidad, audiencias jóvenes

### 12️⃣ Plot Twist
**Objetivo:** Sorpresa narrativa que rompe expectativa
**Energía:** Media | **Retención:** Expectativa rota
**Estructura:** Historia aparentemente predecible → Desarrollo normal → Giro inesperado → Reflexión
**Ideal para:** Audiencias que ya conocen el tema — los sorprendes con el ángulo

### 13️⃣ Mini Documental / Vlog
**Objetivo:** Profundidad y credibilidad
**Producción:** Media-Alta | **B-roll:** Alto
**Estructura:** Objetivo → Obstáculo → Proceso → Resultado
**Ideal para:** Mostrar detrás de escenas, procesos reales, resultados

### 33️⃣ Situación Real
**Objetivo:** Conexión desde lo cotidiano
**Estructura:** Escena cotidiana reconocible → Conflicto → Solución
**Ideal para:** Identificación rápida, humor leve, humanización de marca

### 37️⃣ Sketch
**Objetivo:** Entretenimiento con mensaje
**Estructura:** Escena 1 → Escena 2 → Remate con mensaje
**Ideal para:** Niches con humor, audiencias más jóvenes

### 38️⃣ Inspiración / Motivación
**Objetivo:** Emoción positiva + mensaje memorable
**Estructura:** Historia → Reflexión → Frase potente de cierre
**Ideal para:** Marca personal, comunidad, momentos de bajo contenido educativo

### 39️⃣ Preguntas Incómodas
**Objetivo:** Honestidad que genera confianza
**Estructura:** Pregunta fuerte (incómoda para el nicho) → Respuesta honesta → Reencuadre
**Ideal para:** Autoridad auténtica, diferenciar de coaches genéricos

### 40️⃣ Formato Íntimo
**Objetivo:** Cercanía y vulnerabilidad estratégica
**Producción:** Muy baja | **Energía:** Baja
**Estructura:** Situación real personal → Confesión o aprendizaje → Consejo desde la experiencia
**Ideal para:** Comunidad fiel, marca personal profunda

## FORMATOS EDUCATIVOS

### 6️⃣ Descubrimiento / Revelación
**Objetivo:** Revelar algo que "no se dice" → viralidad educativa
**Energía:** Media | **Producción:** Baja | **Retención:** Curiosity gap
**Estructura:** Problema común → "Lo que nadie te dice…" → Explicación → Cómo aplicarlo
**Gancho:** "Nadie te dice esto…" / "Nunca van a creer lo que descubrí…"
**Ideal para:** Autoridad y viralidad, desmitificar creencias del nicho

### 7️⃣ Metáfora Física / Visual (Hack con Objeto)
**Objetivo:** Simplificar conceptos complejos con un objeto real
**Energía:** Media | **Producción:** Media | **Cámara:** Recomendable
**Estructura:** Mostrar objeto → Explicar la analogía con el concepto → Aplicar al nicho del usuario
**Gancho:** Mostrar el objeto en cámara antes de hablar
**Ideal para:** Educación didáctica, hacer "clic" en audiencias que no entienden conceptos abstractos

### 17️⃣ Problema → Solución Rápida
**Objetivo:** Claridad extrema y valor inmediato
**Estructura:** Problema 1 → Solución / Problema 2 → Solución / Problema 3 → Solución
**Ideal para:** Tips prácticos, contenido de alto valor percibido rápido

### 18️⃣ Atajo Rápido
**Objetivo:** Micro valor en 5–12 segundos
**Producción:** Muy baja
**Estructura:** Gancho → Consejo de 1 sola oración → Cierre
**Ideal para:** Algoritmos de contenido corto, alto volumen de publicación

### 19️⃣ Hack con Objetos Físicos
**Objetivo:** Demostración tangible paso a paso
**Estructura:** Paso 1 con objeto → Paso 2 → Paso 3 → Resultado visible
**Ideal para:** Nichos de lifestyle, salud, fitness, cocina, productividad física

### 21️⃣ Tutorial Paso a Paso
**Objetivo:** Educación clara y accionable
**Estructura:** Qué lograrás → Paso 1 → Paso 2 → Paso 3 → Error común a evitar
**Ideal para:** Procedimientos, software, habilidades técnicas

### 22️⃣ Pizarra
**Objetivo:** Claridad visual para conceptos complejos
**Producción:** Baja (solo una pizarra, hoja o app de notas)
**Estructura:** Problema → Diagrama visual → Explicación → Cómo aplicarlo
**Ideal para:** Conceptos que necesitan ser "dibujados" para entenderse

### 24️⃣ Lista de Ideas
**Objetivo:** Retención por enumeración
**Estructura:** Gancho ("X cosas que…") → Idea 1 → Idea 2 → Idea 3 → Conclusión accionable
**Ideal para:** SEO de contenido, guardar y compartir, alto valor percibido

### 25️⃣ Roba Estos Ejemplos
**Objetivo:** Inspiración directamente accionable
**Estructura:** Ejemplo real → Por qué funciona → Cómo adaptarlo a tu caso
**Ideal para:** Creadores de contenido, marketers, vendedores

### 26️⃣ Mejores Herramientas
**Objetivo:** Valor práctico con recomendaciones concretas
**Estructura:** Problema → Herramienta → Cómo usarla exactamente
**Ideal para:** Nichos de productividad, tecnología, marketing

### 27️⃣ Errores que No Debes Cometer
**Objetivo:** Prevención y advertencia
**Estructura:** Error → Consecuencia real → Solución
**Ideal para:** Audiencias que están empezando, alto engagement por identificación

### 29️⃣ Niveles
**Objetivo:** Segmentar audiencia y entregar valor en cada nivel
**Estructura:** Nivel básico → Nivel intermedio → Nivel avanzado
**Ideal para:** Educación, fitness, finanzas, habilidades profesionales

### 30️⃣ Factos Rápidos
**Objetivo:** Datos sorprendentes en formato ultra dinámico
**Producción:** Baja | **Cortes:** Cada 2–3 segundos
**Estructura:** Dato 1 (corte) → Dato 2 (corte) → Dato 3 → Dato que más impacta al final
**Ideal para:** Nichos con estadísticas, ciencia, historia, negocios

### 31️⃣ Desmintiendo Mitos
**Objetivo:** Corregir creencias falsas del nicho → autoridad
**Estructura:** Mito 1 ("Todos creen que…") → Realidad → Explicación
**Ideal para:** Nichos saturados donde el creador quiere diferenciarse

### 32️⃣ Síntomas / Señales
**Objetivo:** Identificación inmediata y urgencia
**Estructura:** "Si te pasa esto, significa que…" → Señal 1 → Señal 2 → Señal 3 → Qué hacer
**Gancho:** "Estos son los síntomas de…"
**Ideal para:** Salud, psicología, negocios, relaciones

## FORMATOS DE COMPARACIÓN

### 5️⃣ Versus (Pantalla Dividida)
**Objetivo:** Comparación clara entre dos opciones o conceptos
**Energía:** Media | **Producción:** Media | **Retención:** Contraste visual
**Estructura:** Definición A → Definición B → Diferencias clave → Cuál elegir y por qué
**Gancho:** "X vs Y: cuál es mejor"
**Ideal para:** Educación, claridad conceptual, audiencias indecisos

### 28️⃣ Diferencias X vs Y
**Objetivo:** Comparación conceptual simple y directa
**Estructura:** Concepto X explicado → Concepto Y explicado → La diferencia que importa
**Ideal para:** Nichos donde hay confusión entre términos o estrategias

## FORMATOS DE IMPACTO RÁPIDO

### 2️⃣ Cinemático (Composición Artística)
**Objetivo:** Impacto visual + posicionamiento premium
**Energía:** Alta visual / Baja verbal | **Producción:** Alta | **B-roll:** Dominante
**Estructura:** Toma estética inicial muy fuerte → Frases cortas y poderosas → Cierre contundente
**Gancho:** Imagen fuerte + texto de impacto en pantalla
**Ideal para:** Marca personal premium, branding visual fuerte

### 3️⃣ Cambio de Planos (Ritmo Alto)
**Objetivo:** Retención por dinamismo visual extremo
**Energía:** Alta | **Producción:** Media | **Cortes:** Rápidos
**Estructura:** Frase 1 (corte) → Frase 2 (corte) → Frase 3 (corte) → Conclusión
**Gancho:** Frase directa + corte inmediato en el primer segundo
**Ideal para:** Tips rápidos, listas, demostrar autoridad sin rodeos

### 11️⃣ Qué Pasaría Si…
**Objetivo:** Curiosidad especulativa que genera debate
**Retención:** Imaginación del espectador
**Estructura:** Escenario hipotético → Consecuencia 1 → Consecuencia 2 → Reflexión final
**Ideal para:** Nichos de estrategia, psicología, negocios, filosofía

### 36️⃣ Acción Extrema / Disruptiva
**Objetivo:** Impacto y memorabilidad
**Estructura:** Acción disruptiva que nadie espera → Explicación del por qué → Mensaje de fondo
**Ideal para:** Creadores que buscan diferenciarse radicalmente

## FORMATOS DE COMUNIDAD Y PRUEBA SOCIAL

### 9️⃣ Reacción a Viral
**Objetivo:** Aprovechar tendencia existente para generar autoridad
**Energía:** Media | **Producción:** Baja
**Estructura:** Mostrar clip viral → Tu opinión → Análisis desde tu expertise → Reflexión aplicable
**Ideal para:** Autoridad contextual, aparecer cuando ya hay tráfico en un tema

### 10️⃣ Experimento Social
**Objetivo:** Validación real con alta impredecibilidad
**Energía:** Alta | **Retención:** Incertidumbre del resultado
**Estructura:** Hipótesis pública → Interacción real (con personas, mercado, algoritmo) → Resultados → Conclusión
**Ideal para:** Alto impacto, credibilidad por transparencia

### 23️⃣ Respuesta a Comentario
**Objetivo:** Comunidad + contenido que ya tiene demanda validada
**Estructura:** Mostrar comentario real → Responder en profundidad → Expandir con lo que no cabe en comentario
**Ideal para:** Creadores con comunidad activa, contenido que "se pide solo"

### 34️⃣ Testimonio / Caso de Éxito
**Objetivo:** Prueba social con narrativa emocional
**Estructura:** Antes (situación inicial) → Proceso (qué hizo diferente) → Después (resultado concreto)
**Ideal para:** Ventas indirectas, autoridad basada en resultados de otros

## FORMATOS ESPECIALES

### 14️⃣ Cinemático Hablando a Cámara
**Objetivo:** Marca personal premium con presencia directa
**Producción:** Alta | **Alternancia:** Toma artística + discurso directo a cámara
**Ideal para:** Creadores que quieren posicionamiento premium sin perder conexión humana

### 15️⃣ Gatillo Emocional
**Objetivo:** Empatía inmediata que abre al mensaje
**Estructura:** Emoción real (nombrarla directamente) → Causa → Conexión con la audiencia → Solución
**Ideal para:** Nichos de salud mental, relaciones, burnout, crianza

### 16️⃣ Faceless
**Objetivo:** Contenido sin aparecer en cámara
**Producción:** Baja | **Formato:** Clips + texto en pantalla
**Estructura:** Frases cortas con clips ilustrativos
**Ideal para:** Creadores que aún no quieren aparecer, niches de información pura

### 20️⃣ "Si te pasa esto…"
**Objetivo:** Identificación inmediata y urgencia de solución
**Estructura:** Situación reconocible → Causa real → Solución concreta
**Gancho:** "Si te pasa esto, es porque…"
**Ideal para:** Audiencias que no saben que tienen el problema

### 35️⃣ Unboxing
**Objetivo:** Curiosidad + entretenimiento
**Estructura:** Caja/producto → Expectativa generada → Revelación → Opinión honesta
**Ideal para:** Reseñas, lanzamientos, herramientas, libros

---

## GUÍA DE SELECCIÓN RÁPIDA

| Si el guion tiene… | Priorizar estos formatos |
|---|---|
| Historia personal | Historia Curiosa, B-Roll, Formato Íntimo, Testimonio |
| Datos o estadísticas | Descubrimiento, Factos Rápidos, Desmintiendo Mitos |
| Pasos o proceso | Tutorial, Pizarra, Hack con Objeto, Atajo Rápido |
| Comparación | Versus, Diferencias X vs Y, Niveles |
| Advertencia o error | Errores, Síntomas, "Si te pasa esto…" |
| Caso de éxito | Testimonio, Experimento, Reacción a Viral |
| Concepto abstracto | Metáfora Física, Plot Twist, Qué Pasaría Si… |
| Poca producción disponible | Faceless, Atajo Rápido, Pizarra, Respuesta a Comentario |
