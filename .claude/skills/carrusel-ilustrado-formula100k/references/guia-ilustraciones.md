# Guía de Ilustraciones — Estilo Xiaohei para F100K

Referencia rápida para la skill `carrusel-ilustrado-formula100k`.
Cada tipo de ilustración incluye: descripción, cuándo usarlo, 3 ejemplos de F100K, y descripción en inglés para el prompt de Higgsfield.

---

## TIPO 1 — Workflow (Proceso Secuencial)

**Cuándo usarlo**
Cuando el contenido explica un proceso que tiene pasos ordenados y necesita que el lector entienda la secuencia. Ideal para metodologías, tutoriales, sistemas de trabajo.

**Señales en el guion:** "paso 1, paso 2", "primero haz X, luego Y", "el proceso es", "en 5 pasos", "cómo funciona"

**Ejemplos F100K**
1. "Los 5 pasos para crear un reel viral: idea → gancho → guion → grabación → publicación" — Xiaohei caminando sobre una línea con 5 círculos numerados
2. "Cómo funciona el Segundo Cerebro F100K: captura → organiza → usa → publica" — Xiaohei subiendo una escalera de 4 peldaños, cada uno con un ícono
3. "El proceso de calendarización semanal: investigar virales → asignar formatos → guionizar → producir → publicar" — Xiaohei en una cinta transportadora con cajas etiquetadas

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei walking along a horizontal timeline path with [N] numbered 
circular nodes connected by right-pointing arrows. Xiaohei stands at the 
[current/midpoint] node, one leg raised mid-stride, arm pointing forward. 
Each node contains a simple flat icon representing: [icon 1], [icon 2], [icon 3].
PROPS: Small step numbers (1, 2, 3) in orange circles above each node.
```

## TIPO 2 — System Locale (Partes de un Sistema)

**Cuándo usarlo**
Cuando quieres mostrar que algo está compuesto de partes que trabajan juntas. Ideal para presentar stacks de herramientas, módulos de un programa, o los componentes de un método.

**Señales en el guion:** "el sistema tiene X partes", "las herramientas que uso son", "el stack es", "los módulos son", "todo funciona junto"

**Ejemplos F100K**
1. "El stack de contenido F100K: Claude Code + Higgsfield + Canva + CapCut" — Xiaohei al centro con 4 cajas flotando alrededor conectadas por líneas delgadas
2. "Los 3 pilares del Segundo Cerebro: ADN de marca + banco de ideas + calendario" — Xiaohei sosteniendo un triángulo con cada pilar en un vértice
3. "El ecosistema F100K: Skool + formula100k.app + Skills + Consola de Contenido" — Xiaohei parado en el centro de un diagrama de Venn con 4 círculos entrelazados

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei standing at exact center of frame, arms slightly spread 
in a "presenting" gesture. [N] labeled rectangular boxes float around Xiaohei 
in a circular arrangement, connected to Xiaohei by thin black arrows. 
Each box contains a simple icon for: [component 1], [component 2], [component 3].
PROPS: Thin connector lines from each box to Xiaohei's center. 
One box highlighted with orange #F59E0B border to indicate the key component.
```

## TIPO 3 — Before/After Contrast (Contraste Comparativo)

**Cuándo usarlo**
Cuando quieres mostrar la transformación que produce tu método o el contraste entre el estado actual y el estado deseado del lector. Muy efectivo para hooks y slides de problema/solución.

**Señales en el guion:** "antes vs. después", "sin [método] vs. con [método]", "el error que cometes", "lo que cambia cuando", "la diferencia entre"

**Ejemplos F100K**
1. "Antes de F100K: publicas sin sistema. Después: pipeline automatizado." — izquierda Xiaohei rodeado de papeles caóticos, derecha Xiaohei frente a una línea ordenada de publicaciones
2. "Sin Segundo Cerebro vs. Con Segundo Cerebro" — izquierda Xiaohei con cabeza llena de interrogantes, derecha Xiaohei con diagrama organizado saliendo de su cabeza
3. "Tu perfil de Skool antes y después de la auditoría" — izquierda Xiaohei mirando una pantalla vacía, derecha Xiaohei mirando una pantalla llena de íconos de personas

**Descripción para prompt (inglés)**
```
CHARACTER: Two instances of Xiaohei divided by a thin vertical center line.
LEFT ZONE (Before/Bad state): Xiaohei surrounded by [chaotic elements: 
scattered papers floating, tangled arrows, question marks, small explosions].
RIGHT ZONE (After/Good state): Same Xiaohei pose but orderly — 
[clean elements: stacked papers, straight arrows, checkmarks, small stars].
PROPS: "ANTES" label area on left, "DESPUÉS" label area on right 
(leave space for Canva text). Orange accent checkmark on right side.
```

## TIPO 4 — Role Status (Estado del Personaje)

**Cuándo usarlo**
Cuando quieres que el lector se identifique con el personaje. El lector ES Xiaohei en esa situación. Muy poderoso para hooks emocionales, slides que describen un dolor o un logro.

**Señales en el guion:** "tú cuando", "eso que sientes cuando", "en el día 1 eras", "después de X meses ya eres", "te reconoces en esto"

**Ejemplos F100K**
1. "Tú el lunes antes de F100K" — Xiaohei sentado en el suelo, papeles cayendo encima, brazos levantados en desesperación
2. "Tú después de implementar el sistema" — Xiaohei de pie sobre una pila de teléfonos, brazo derecho levantado, estrella naranja encima
3. "Tú mirando el reloj a las 11pm sin haber publicado nada" — Xiaohei mirando un reloj gigante con aguja apuntando a las 11, expresión de pánico (cabeza inclinada)

**Posturas expresivas de Xiaohei — catálogo:**
- **Abrumado**: sentado en piso, múltiples objetos flotando alrededor, brazos levantados
- **Enfocado**: inclinado hacia adelante, un ojo en lupa mirando pantalla, una mano en el mentón
- **Victorioso**: de pie erguido, un brazo arriba, pequeño estallido de estrellas sobre la cabeza
- **Confundido**: cabeza ladeada 45°, signo de interrogación flotando al lado
- **Agotado**: sentado con espalda encorvada, líneas de cansancio saliendo de la cabeza
- **En pánico**: corriendo, objetos cayendo detrás, pequeñas exclamaciones flotando
- **Seguro**: brazos cruzados, postura vertical, pequeña corona naranja encima

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei in a [specific expressive pose from catalog above].
Pose details: [describe exact body position, angle, direction facing].
EMOTIONAL PROPS: [floating objects that reinforce the emotional state — 
papers, question marks, stars, clock, notifications, etc.]
COMPOSITION: Xiaohei centered, props arranged in the surrounding white space.
The emotional atmosphere should be immediately readable at a glance.
```

## TIPO 5 — Concept Metaphor (Metáfora Visual)

**Cuándo usarlo**
Cuando necesitas hacer tangible un concepto abstracto. En lugar de explicar qué es "el algoritmo" o "el engagement", lo conviertes en un objeto físico que Xiaohei manipula. Muy efectivo para slides de educación conceptual.

**Señales en el guion:** "el algoritmo es como", "piensa en X como un", "imagina que", conceptos abstractos como engagement, autoridad, conversión, alcance, comunidad

**Ejemplos F100K**
1. "El algoritmo es un megáfono — Xiaohei gritando a través de un megáfono gigante hacia siluetas pequeñas a lo lejos"
2. "El engagement es un imán — Xiaohei sosteniendo un imán gigante en forma de U que atrae pequeñas figuras de personas hacia él"
3. "Tu autoridad de marca es una llave — Xiaohei insertando una llave gigante en una cerradura, del otro lado se ve una multitud esperando entrar"

**Tabla de objetos-metáfora más usados:**

| Concepto abstracto | Objeto literal | Descripción en inglés |
|-------------------|----------------|----------------------|
| Algoritmo | Megáfono gigante | giant megaphone, Xiaohei shouting through it, sound waves illustrated as concentric arcs |
| Engagement | Imán en U | giant U-shaped magnet, small stick figures being pulled toward it magnetically |
| Autoridad | Llave + cerradura | oversized skeleton key, Xiaohei inserting it into a door lock, crowd visible through the keyhole |
| Conversión | Embudo | large funnel, small figures entering at top, fewer exiting at bottom with stars |
| Alcance | Telescopio | Xiaohei looking through a giant telescope, sight lines extending across the frame |
| Comunidad | Círculo de figuras | Xiaohei at center of a ring of smaller stick figures holding hands |
| Contenido viral | Cadena de dominós | Xiaohei flicking first domino, long chain of tiles falling in perspective |
| Consistencia | Reloj de cuerda | Xiaohei cranking a giant wind-up clock key on the back of a large clock |
| Estrategia | Tablero de ajedrez | Xiaohei studying a giant chess board, moving a piece with one finger |
| Crecimiento | Planta/árbol | small seedling growing from a tiny pot, Xiaohei watering it, plant slightly taller than Xiaohei |

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei interacting with a [metaphor object — much larger than Xiaohei, 
approximately 60-70% of frame height]. Xiaohei appears small but in complete 
control of the giant object — [specific interaction: holding, pulling, inserting, 
looking through, watering, etc.].
COMPOSITION: Metaphor object dominates frame. Xiaohei at its base or side.
Orange accent on the key element of the metaphor object.
```

## TIPO 6 — Method Layering (Capas de una Metodología)

**Cuándo usarlo**
Cuando tu contenido tiene una jerarquía clara: niveles, fases, capas que se construyen unas sobre otras. Transmite que hay una estructura sólida y un orden lógico de construcción.

**Señales en el guion:** "los 3 niveles de", "la pirámide de", "las capas son", "primero hay que tener X antes de Y", "la base es", "construido sobre"

**Ejemplos F100K**
1. "Las 3 capas del contenido viral: emoción (base) → información (medio) → CTA (cima)" — Xiaohei en la cima de una pirámide de 3 bloques, brazo extendido señalando hacia arriba
2. "Los niveles de F100K: Skills → Segundo Cerebro → Consola de Contenido → Comunidad" — Xiaohei construyendo el último bloque sobre una torre de 4 niveles
3. "La jerarquía de tus ingresos digitales: audiencia → comunidad → producto → membresía" — Xiaohei sosteniendo un signo de estrella naranja encima de la estructura piramidal completa

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei standing at the apex of a [N]-level pyramid/stack structure.
Each level is a wide flat rectangular platform, getting narrower toward the top.
The bottom layer is the widest. Xiaohei is at the very top, arms spread wide 
in a "complete/victorious" pose.
PROPS: Each layer has a simple icon centered on its surface. 
The top layer has an orange #F59E0B highlight to indicate the achieved goal.
Thin ascending arrows on the sides of the structure indicate direction of growth.
```

## TIPO 7 — Map/Route (Navegación y Caminos)

**Cuándo usarlo**
Cuando quieres mostrar un journey, un roadmap, o la secuencia de estados por los que pasa alguien. Muy efectivo para mostrar el journey de la audiencia, el proceso de transformación del cliente, o las fases de un programa.

**Señales en el guion:** "el journey de tu audiencia", "el camino desde X hasta Y", "las fases del programa", "primero son extraños, luego fans", "el roadmap es"

**Ejemplos F100K**
1. "El journey de tu audiencia: extraño → seguidor → fan → cliente → evangelista" — Xiaohei viajando en una bicicleta simple por un camino ondulado con 5 banderas de colores
2. "El roadmap de F100K en 90 días: semana 1 configuración → semanas 2-4 primeras publicaciones → mes 2 consistencia → mes 3 resultados" — Xiaohei con mochila caminando por un mapa estilo videojuego retro con 4 zonas
3. "Tu camino como creadora: primera publicación → primeros 100 seguidores → primera venta → negocio digital" — Xiaohei en el punto de partida mirando hacia adelante, camino visible con puntos de decisión

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei traveling along a winding path that connects [N] waypoints.
Xiaohei is positioned at [starting point / midpoint] of the journey, 
moving in the direction of the destination. At a fork in the path (if applicable), 
Xiaohei has one arm raised pointing toward the correct direction.
PATH: S-curve or Z-pattern across the full frame, starting at bottom-left, 
ending at top-right. Each waypoint is a small filled circle with space above it 
for Canva labels. The destination waypoint has an orange #F59E0B star above it.
PROPS: Small milestone markers (flags, signs) at each waypoint.
```

## TIPO 8 — Comic Strip Sequence (Narrativa Multi-panel)

**Cuándo usarlo**
Cuando quieres contar una historia o situación en 3-4 momentos. Muy efectivo para el clásico "esto te ha pasado", para mostrar la transformación, o para narrar un insight de forma entretenida. Alto potencial de shares.

**Señales en el guion:** "¿te ha pasado que", "imagina la situación", "esto es lo que suele pasar", narrativas de antes/proceso/después con saltos de tiempo

**Ejemplos F100K**
1. "P1: Publicas algo → P2: Nadie responde → P3: Revisas el hook → P4: Cambias una palabra, 50K views"
2. "P1: Día 1 sin saber qué publicar → P2: Descargas el Segundo Cerebro → P3: Tienes 30 ideas → P4: Calendario listo para el mes"
3. "P1: 'No tengo tiempo para contenido' → P2: Conoces las skills de IA → P3: 1 hora = 10 piezas → P4: Ya tienes tiempo"

**Descripción para prompt (inglés)**
```
CHARACTER: Xiaohei appears in [3 or 4] equal-sized panels arranged in 
a [2x2 grid / horizontal strip].
Panel 1: [Xiaohei in initial situation — describe pose and context props]
Panel 2: [Xiaohei in development moment — different pose, different props]
Panel 3: [Xiaohei at turning point — clear shift in body language]
Panel 4: [Xiaohei at resolution — victorious/relieved/transformed pose]
COMPOSITION: Thin black border lines (2px) separate panels. All panels equal size.
Xiaohei's expression and posture must change visibly between panels.
Each panel has white space at top or bottom for Canva text captions.
```

## COMBINACIONES RECOMENDADAS POR FORMATO

### Carrusel educativo (enseñar un concepto)
- Slide 1: **Concept Metaphor** (hook visual fuerte)
- Slides 2-4: **Workflow** (paso a paso del concepto)
- Slide 5: **Method Layering** (visión completa del sistema)
- Slide 6: **Role Status** (CTA — "tú en el mes 3")

### Carrusel de venta (presentar un programa/producto)
- Slide 1: **Role Status** (dolor actual del lector)
- Slide 2: **Before/After Contrast** (la transformación)
- Slide 3-4: **System Locale** (qué incluye el programa)
- Slide 5: **Map/Route** (el journey dentro del programa)
- Slide 6: **Role Status** (el estado final logrado)

### Carrusel de storytelling (anécdota + insight)
- Slide 1: **Role Status** o **Comic Strip Sequence** (situación de arranque)
- Slides 2-4: **Comic Strip Sequence** (desarrollo de la historia)
- Slide 5: **Concept Metaphor** (el insight revelado)
- Slide 6: **Role Status** (el lector en el estado transformado)

### Carrusel de herramientas/recursos (listado)
- Slide 1: **Concept Metaphor** (por qué estas herramientas importan)
- Slides 2-5: **System Locale** (una herramienta por slide con sus partes)
- Slide 6: **Method Layering** (jerarquía de uso recomendada)
