# Extracción del ADN de Estilo — guía detallada

Rellenar esta ficha mirando la(s) captura(s). Aproximar valores; no hace falta exactitud milimétrica, sí coherencia.

## Ficha de ADN (rellenar siempre)

```
REFERENTE: @____  ·  formato detectado: 4:5 / 1:1 / 9:16

1. LAYOUT
   - Alineación del título: izquierda / centro / derecha
   - Posición del título: arriba / centro / abajo
   - Márgenes: anchos / medios / sangrado completo
   - Densidad: minimalista (1 idea) / medio / denso

2. TIPOGRAFÍA
   - Familia título: serif display / sans geométrica / condensada / manuscrita / mono
   - Fuente Google aproximada: ____
   - Familia cuerpo: ____  →  Google aprox: ____
   - Caso: MAYÚSCULAS / Capital / minúsculas
   - Tracking: apretado / normal / amplio
   - Contraste de tamaño título:cuerpo (ej. 4:1)

3. PALETA (HEX aproximado)
   - Fondo: #____   (claro / oscuro)
   - Texto: #____
   - Acento 1: #____
   - Acento 2: #____ (si hay)
   - Plano / degradado / con foto de fondo

4. PATRÓN DE GANCHO (portada)
   - Tipo: pregunta / número / promesa / contraste / error común / "esto te pasa"
   - Estructura de la frase: ____

5. ARQUITECTURA
   - Nº de slides: ____
   - Mapa: S1 hook → S2 ____ → … → SN CTA
   - Ritmo: 1 idea/slide / 2 ideas / denso

6. DECORACIÓN / TEXTURA
   - Elementos: líneas / formas / stickers / flechas / números / sombras / cajas / mockups
   - Fondo: liso / textura / patrón / foto
   - Sombras: sí (dura/suave) / no

7. TRATAMIENTO DE FOTO
   - ¿Usa persona? sí / no
   - Forma: cutout recortado / polaroid / círculo / rectángulo / fondo completo
   - Filtro/tono: ____

8. CTA / CIERRE
   - Acción: comentar palabra / guardar / seguir / link / DM
   - Forma: botón / texto / sticker / flecha
```

## Cómo aproximar fuentes desde una imagen

| Lo que ves | Google Font cercana |
|---|---|
| Serif elegante de alto contraste | Playfair Display, DM Serif Display |
| Serif moderno editorial | Fraunces, Lora |
| Sans geométrica redonda | Poppins, Quicksand |
| Sans neutra de UI | Inter, DM Sans |
| Sans técnica/startup | Space Grotesk |
| Condensada de impacto | Bebas Neue, Archivo Narrow, Anton |
| Manuscrita | Caveat, Patrick Hand |
| Monoespaciada | Space Mono, JetBrains Mono |

## Cómo aproximar HEX

- Identificar fondo, texto y acento principal por inspección visual.
- Crema/marfil ≈ `#F5EFE0`–`#FAF6EE`; off-white ≈ `#F7F7F5`; negro suave ≈ `#1A1A1A`–`#111`.
- Acentos saturados: nombrarlos (coral, mostaza, verde menta, azul klein) y dar un HEX plausible.
- Si hay degradado, anotar los dos extremos.
