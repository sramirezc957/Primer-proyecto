# 10 Dimensiones de Análisis · Benchmark de Producto F100K

Cada competidor se evalúa en estas 10 dimensiones. Escala 0-5 + nota cualitativa.

---

## 1. POSICIONAMIENTO

**Qué medimos:** qué tan claro y único es el ángulo del competidor.

| Score | Criterio |
|-------|----------|
| 5 | Vehículo único nombrado + promesa específica + diferenciación visible en hero |
| 4 | Promesa clara, vehículo único existe pero no destacado |
| 3 | Promesa genérica del nicho, sin vehículo propio |
| 2 | Copia textual de competidores (mismo hook, misma promesa) |
| 1 | Confuso, no se entiende qué venden |
| 0 | Sin headline o sin landing visible |

**Preguntas:**
- ¿Tiene un nombre propio para su método? (ej: "Fórmula 100K", "Sistema MEDDIC")
- ¿La promesa es específica con números/tiempo? (ej: "0 a $10K/mes en 90 días")
- ¿Se entiende a primera vista a quién va dirigido?

---

## 2. PRICING

**Qué medimos:** estructura de precios, escalera, transparencia.

| Score | Criterio |
|-------|----------|
| 5 | Múltiples tiers claros, escalera de valor visible, descuento anual evidente |
| 4 | 1-2 tiers claros con pricing público |
| 3 | Pricing público pero plano (1 solo plan) |
| 2 | Pricing oculto detrás de call/aplicación |
| 1 | Pricing inconsistente entre páginas |
| 0 | Sin pricing en ningún lado |

**Datos a registrar:**
- Modelo: mensual / anual / lifetime / one-time / hibrido
- Rango: precio entry → precio top
- Descuentos: lanzamiento, anual, founding members
- Add-ons / upsells visibles
- Garantía (devolución, sin riesgo, etc.)

---

## 3. MECÁNICA DE OFERTA

**Qué medimos:** cómo construyen valor más allá del producto core.

| Score | Criterio |
|-------|----------|
| 5 | Bonos nombrados con valor monetario + garantía fuerte + urgencia legítima |
| 4 | 3+ bonos claros + garantía |
| 3 | Bonos genéricos sin valor asignado |
| 2 | Solo producto core, sin bonos |
| 1 | Sin garantía ni reducción de riesgo |
| 0 | Sin oferta clara |

**Checklist:**
- [ ] Bonos nombrados (con valor $)
- [ ] Garantía (días, condiciones)
- [ ] Stack value visible
- [ ] Urgencia (cohorte, fecha límite)
- [ ] Escasez (plazas limitadas)
- [ ] CTA único y claro

---

## 4. PRODUCTO

**Qué medimos:** qué entrega realmente el producto.

| Score | Criterio |
|-------|----------|
| 5 | Roadmap visible + N módulos + comunidad + Q&A + recursos + soporte |
| 4 | Buen contenido + 2-3 entregables complementarios |
| 3 | Solo el contenido core (módulos / sesiones) |
| 2 | Producto difuso, no se sabe qué entrega |
| 1 | Promesa sin entregable visible |
| 0 | No se entiende qué incluye |

**Datos a registrar:**
- Estructura: módulos / fases / sprints / sesiones
- N entregables principales
- ¿Tiene comunidad? (Skool / Circle / Discord / FB Group)
- ¿Tiene Q&A en vivo? Frecuencia
- ¿Tiene recursos descargables? Cuántos
- ¿Tiene certificación?

---

## 5. AVATAR

**Qué medimos:** qué tan bien definido y específico es el cliente ideal.

| Score | Criterio |
|-------|----------|
| 5 | Avatar nombrado, situación específica, lenguaje propio del avatar |
| 4 | Avatar claro pero genérico (ej: "emprendedoras") |
| 3 | Avatar implícito por el lenguaje |
| 2 | Apela a "todos" |
| 1 | Confuso a quién le habla |
| 0 | Sin avatar identificable |

**Nivel de consciencia** (Schwartz):
- ¿Para qué nivel está escrita la landing?
  - Más consciente (sabe del producto)
  - Consciente del producto
  - Consciente de la solución
  - Consciente del problema
  - Inconsciente
- Esto define con qué hook puedes competirles

---

## 6. MARKETING / CAPTACIÓN

**Qué medimos:** dónde y cómo atraen tráfico.

| Score | Criterio |
|-------|----------|
| 5 | Presencia fuerte en 3+ canales + ads activos + funnel orgánico bien diseñado |
| 4 | 2 canales fuertes + algo de paid |
| 3 | 1 canal principal con buen contenido |
| 2 | Solo SEO o solo orgánico esporádico |
| 1 | Sin presencia visible más allá de la landing |
| 0 | Tráfico desconocido / sin actividad |

**Datos a registrar:**
- Canales principales: IG / TikTok / YouTube / LinkedIn / Twitter / Podcast
- # seguidores en cada uno
- Tipo de contenido dominante: educativo / inspiracional / venta / mix
- ¿Tiene ads activos? (Meta Ad Library)
- ¿Tiene lead magnet? Cuál
- ¿Tiene webinar/VSL? Cuál es el funnel

---

## 7. SOCIAL PROOF

**Qué medimos:** evidencia de que el producto funciona.

| Score | Criterio |
|-------|----------|
| 5 | 20+ testimonios con caso específico + casos de estudio + reviews externas (G2/Trustpilot) |
| 4 | 10-20 testimonios variados |
| 3 | 5-10 testimonios visibles |
| 2 | 1-5 testimonios genéricos |
| 1 | Sin testimonios pero con menciones de "X estudiantes" |
| 0 | Sin social proof |

**Datos a registrar:**
- # testimonios visibles
- Tipo: texto / screenshot / video / caso de estudio
- ¿Específicos? (números, contexto) o ¿genéricos?
- Rating en G2/Capterra/Trustpilot (si aplica)
- # reviews en Google / Trustpilot

---

## 8. TECH STACK

**Qué medimos:** plataforma y stack tecnológico.

| Score | Criterio |
|-------|----------|
| 5 | Stack moderno y eficiente para el modelo de negocio |
| 4 | Stack adecuado |
| 3 | Stack funcional pero anticuado |
| 2 | Stack que limita su crecimiento |
| 1 | Stack roto / múltiples bugs visibles |
| 0 | Sin tech visible |

**Datos a registrar (BuiltWith / Wappalyzer):**
- Plataforma de comunidad: Skool / Circle / Mighty / Discord / Slack
- Plataforma de pagos: Stripe / PayPal / Hotmart / nativo
- Email marketing: ActiveCampaign / ConvertKit / Mailchimp / nativo
- LMS: Kajabi / Teachable / Thinkific / nativo / Skool classroom
- Analytics: GA / Mixpanel / Plausible / nada
- CRM: HubSpot / Pipedrive / nada

---

## 9. AUTORIDAD / MARCA PERSONAL

**Qué medimos:** quién está detrás y qué credibilidad tiene.

| Score | Criterio |
|-------|----------|
| 5 | Fundador con marca personal fuerte + media mentions + libro/podcast propio |
| 4 | Fundador conocido en el nicho |
| 3 | Fundador con trayectoria visible |
| 2 | Fundador anónimo pero equipo visible |
| 1 | Marca sin caras |
| 0 | Sin información de quién está detrás |

**Datos a registrar:**
- Nombre del fundador / equipo
- Trayectoria visible (LinkedIn, libro, exit previo, etc.)
- Media mentions (entrevistas, podcasts famosos, prensa)
- # seguidores combinados (marca + fundador personal)
- ¿Tiene libro / podcast / curso emblema?

---

## 10. COMUNIDAD / RETENCIÓN

**Qué medimos:** qué tan fuerte es la comunidad y la retención del producto.

| Score | Criterio |
|-------|----------|
| 5 | Comunidad activa con eventos semanales + gamificación + casos de miembros |
| 4 | Comunidad existe y se ve actividad |
| 3 | Comunidad pero baja interacción visible |
| 2 | Comunidad solo nominal |
| 1 | Sin comunidad |
| 0 | Sin data |

**Datos a registrar:**
- ¿Hay comunidad? Plataforma
- # miembros (si visible)
- Frecuencia de eventos en vivo
- ¿Gamificación? (puntos, niveles, leaderboard)
- Retención visible (testimonios mencionan tiempo de permanencia)
- ¿Casos de éxito celebrados públicamente?

---

## 📊 SCORE TOTAL Y CLASIFICACIÓN

Suma de las 10 dimensiones → rango 0-50.

| Total | Clasificación | Implicación |
|-------|---------------|-------------|
| 45-50 | **Líder de mercado** | Estudiar para no copiar — buscar gaps. |
| 35-44 | **Competidor fuerte** | Aprender de sus fortalezas, buscar sus debilidades. |
| 25-34 | **Competidor estándar** | Tu cliente debe superar este nivel. |
| 15-24 | **Vulnerable** | Oportunidades claras de superarlos. |
| 0-14 | **Marginal** | No es competencia real — descartar. |

---

## ⚠ NOTAS IMPORTANTES

1. **No bajar el score por gusto personal** — solo por evidencia objetiva.
2. **Si un dato no es visible**, marcar como "n/v" (no visible) y NO inventar.
3. **Distinguir entre "oculto a propósito"** (estrategia, ej: pricing en call) y "ausente por descuido".
4. **Anotar fortalezas Y debilidades** en cada dimensión, incluso si el score es bajo.
