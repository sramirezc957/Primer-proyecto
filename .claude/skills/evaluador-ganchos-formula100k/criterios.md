# Criterios de Evaluación · Ganchos Virales FÓRMULA 100K

Rúbrica completa para evaluar el primer segundo de un video. Se aplica en orden: Test del 1 Segundo → Forma Visual → E.N.C. → Gatillos → Gancho Textual → Score final.

---

## 1. TEST DEL 1 SEGUNDO (eliminatorio · 25 pts)

**Criterio único:** Al ver la captura sin contexto y sin audio, ¿se entiende de qué va el video?

| Resultado | Puntos | Significado |
|-----------|--------|-------------|
| ✓ Se entiende perfecto | 25 | Pasa el test maestro |
| ⚠ Se intuye, pero hay duda | 12 | Hay un fallo en E o C |
| ✗ No se entiende nada | 0 | Reconstruir desde cero |

**Aplicación:** Mira la imagen. Cuenta hasta 1. ¿Qué pensaste? Si tu primer pensamiento NO coincide con la promesa del video, el test falla.

---

## 2. IDENTIFICACIÓN DE LA FORMA VISUAL (10 pts)

Identifica cuál de las 5 Formas se está usando y evalúa qué tan bien se ejecuta.

### F1 — Sujeto Protagonista + Texto Contextualizador
**Marcadores:** Persona en plano medio/primer plano + texto corto encima o al lado + gesto visible (señalar, sostener).
**Bien ejecutada:** Rostro claro, texto ≤8 palabras, gesto que apoya el texto.

### F2 — Acción Simbólica + Subtítulo
**Marcadores:** Manos haciendo algo (verter, cortar, encender) en primer plano + texto lateral breve.
**Bien ejecutada:** Acción inequívoca, texto que nombra la idea, fondo limpio.

### F3 — Título Protagonista + Sujeto Secundario
**Marcadores:** Texto grande dominante (1/3 superior o más) + persona en segundo plano respaldando.
**Bien ejecutada:** Título legible en 1 mirada, sujeto no compite con el texto.

### F4 — Imagen Viral/Simbólica + Texto Guía
**Marcadores:** Imagen sorprendente, surrealista o impactante en primer plano + texto que orienta el significado.
**Bien ejecutada:** Imagen comprensible (no shock vacío), texto guía 5-7 palabras.

### F5 — Movimiento Disruptivo + Corte Rápido
**Marcadores:** Difícil de evaluar en captura estática. Se ve si la imagen captura un instante de movimiento extremo (objeto entrando de golpe, cámara en ángulo raro, momento de transición).
**Bien ejecutada:** Solo evaluable con video. En captura, anota "requiere ver el video completo".

### Forma híbrida
Si combina elementos de 2 formas (ej: F1+F4 = persona + imagen viral), nómbrala como híbrida y evalúa ambos componentes.

### Forma indefinida
Si no encaja en ninguna, anótalo. Es señal de gancho mal estructurado (penalización -5 pts).

**Puntuación de la Forma:**
- Forma clara y bien ejecutada: 10 pts
- Forma clara pero ejecución débil: 5 pts
- Forma indefinida: 0 pts

---

## 3. SISTEMA E.N.C. (30 pts · 10 pts cada componente)

### E — Estímulo Núcleo (10 pts)

**Pregunta clave:** ¿Hay UN protagonista visual claro?

| Sub-criterio | Sí (2 pts) | No (0 pts) |
|--------------|-----------|-----------|
| ¿Hay un único foco visual dominante? | ✓ | ✗ |
| ¿Está nítido (no borroso ni perdido)? | ✓ | ✗ |
| ¿Contrasta con el fondo? | ✓ | ✗ |
| ¿Está bien posicionado (centro o tercios)? | ✓ | ✗ |
| ¿Hay un verbo/gesto/acción visible? | ✓ | ✗ |

**Errores típicos en E:**
- Pequeño/lejos: subir plano (medio/primer plano)
- Se pierde en fondo: separar con luz, color o desenfoque
- Ambiguo: cambiar a un verbo visible

### N — Nivel de Carga Cognitiva (10 pts)

**Pregunta clave:** ¿Qué tan fácil entiende el cerebro lo que ve?

**Conteo de elementos activos en pantalla:**
- 1-3 elementos: BAJA carga ✓ (10 pts)
- 4-5 elementos: MEDIA carga ⚠ (5 pts)
- 6+ elementos: ALTA carga ✗ (0 pts)

**Sub-criterios adicionales:**
- ¿Hay solo 1 idea visible? → Si sí, suma 0 (ya está incluido). Si no, resta 3.
- ¿El fondo está limpio? → Si caótico (libros, plantas, cuadros, gente moviéndose detrás), resta 2.
- ¿Hay subtítulos compitiendo con el gancho textual? → Si sí, resta 2.

**Errores típicos en N:**
- Fondo cargado: limpiar o desenfocar
- Demasiado texto: reducir a 5-8 palabras
- Múltiples ideas: dejar solo 1

### C — Contextualización Jerárquica (10 pts)

**Pregunta clave:** ¿Los apoyos refuerzan al E o lo opacan?

**Conteo de apoyos:**
- 0 apoyos: 5 pts (no opaca, pero podría ayudar)
- 1-2 apoyos bien usados: 10 pts ✓
- 3+ apoyos: 0 pts ✗ (compiten con E)

**Sub-criterios:**
- ¿Los apoyos son más pequeños y menos saturados que el E? Si sí: ✓
- ¿Los apoyos apuntan o señalan al E (flecha, mirada)? Si sí: ✓
- ¿Hay un rótulo/etiqueta breve que contextualice? Si sí: bonus +2

**Apoyos válidos:** flecha, rótulo breve, prop simbólico (balanza, candado, imán), icono pequeño.
**Apoyos inválidos:** plantas decorativas, libros random, elementos del fondo natural.

---

## 4. GATILLOS DE VIRALIDAD (20 pts)

**Detecta cuáles de los 15 gatillos activa el gancho.** Cuenta máx 3 gatillos para el score.

| # | Gatillo | Señales para detectarlo |
|---|---------|------------------------|
| 1 | Curiosidad (Curiosity Gap) | Loop abierto, secreto prometido, "lo que nadie te dice" |
| 2 | Sorpresa | Imagen disruptiva, dato fuera de lugar, contraste fuerte |
| 3 | Identificación | Situación cotidiana específica que la audiencia vive |
| 4 | Controversia | Niega creencia popular, "X no es lo que crees" |
| 5 | Autoridad | Cifras, resultados, credenciales visibles |
| 6 | FOMO | "Si no haces X, pierdes Y", urgencia temporal |
| 7 | Transformación | Antes/después, dos estados contrastados |
| 8 | Simplicidad | Pocos pasos, números bajos, "fácil de replicar" |
| 9 | Secreto | "Truco oculto", "lo que los gurús no cuentan" |
| 10 | Validación Emocional | Nombra una emoción específica que duele |
| 11 | Conflicto | Dos ideas opuestas en tensión |
| 12 | Revelación | Cambio de paradigma, "lo que crees está mal" |
| 13 | Humor | Exageración, situación absurda, autocrítica |
| 14 | Desafío | Reto al espectador, "intenta no..." |
| 15 | Utilidad Inmediata | Aplicable hoy, gratificación instantánea |

**Puntuación:**
- 0 gatillos detectados: 0 pts (gancho plano, no engancha)
- 1 gatillo bien activado: 7 pts
- 2 gatillos combinados: 14 pts
- 3+ gatillos combinados: 20 pts

**Importante:** Detectar ≠ activado. Un gatillo está ACTIVADO si la captura genera ESA emoción específica. Si solo "podría" generarla, no cuenta.

---

## 5. GANCHO TEXTUAL (15 pts · solo si hay texto)

Si NO hay texto visible en el primer segundo, redistribuir 15 pts entre E.N.C. y Gatillos (proporcional).

### A) Cantidad de palabras (5 pts)
- ≤5 palabras: 5 pts
- 6-8 palabras: 4 pts
- 9-10 palabras: 2 pts
- 11+ palabras: 0 pts

### B) Anatomía Visual (5 pts)
- Tamaño 7-12% del frame: 1 pt
- Alto contraste (negro/beige, blanco/negro o caja sólida): 1 pt
- Zona segura (margen 5-8% desde bordes): 1 pt
- Tipografía nativa o premium (NO genérica tipo Arial sin personalidad): 1 pt
- Quiebre de línea lógico (si hay 2 líneas): 1 pt

### C) Estructura de copywriting (5 pts)
Identifica si usa una de las 4 estructuras:
- A. Curiosidad (Loop Abierto): "[Resultado] usando el método [Nombre]"
- B. Puntos de Dolor: "Deja de [acción] si quieres [resultado]"
- C. Resultado Soñado: "[Número] pasos para [beneficio específico]"
- D. Susurro (paréntesis): "[Promesa] ([dato extra])"

- Usa una estructura claramente: 5 pts
- Estructura débil: 2 pts
- Texto plano sin estructura: 0 pts

**Bonus:** Si tiene paréntesis tipo Susurro (intriga o seguridad), suma +2 pts (máx total 15).

---

## 6. CÁLCULO DEL SCORE FINAL

```
SCORE = Test 1s (25) + Forma Visual (10) + E.N.C. (30) + Gatillos (20) + Textual (15)
       = ___ / 100
```

**Bandas de calidad:**

| Score | Banda | Acción |
|-------|-------|--------|
| 85-100 | 🏆 Top 10% | Listo para publicar |
| 70-84 | ⭐ Viable | Ajustes menores antes de publicar |
| 50-69 | 💪 Iterar | Necesita 2-3 cambios significativos |
| 30-49 | 📖 Repensar | Cambiar de Forma o reestructurar |
| 0-29 | 🚨 Reconstruir | Empezar desde cero |

---

## 7. ERRORES FATALES (penalizaciones globales)

Si detectas alguno de estos, aplica penalización adicional:

| Error fatal | Penalización |
|-------------|--------------|
| Saludo cliché visible ("Hola chicas") | -10 |
| Sin protagonista identificable | -10 |
| Más de 6 elementos compitiendo | -8 |
| Texto ilegible (muy fino, muy chico, sin contraste) | -8 |
| Promesa vaga ("Esto te va a sorprender") | -5 |
| Movimiento sin propósito visible | -5 |
| Tipografía genérica de aplicación nativa sin trabajar | -3 |

**Nota:** Las penalizaciones se aplican AL FINAL. El score nunca baja de 0.

---

## 8. SEÑALES DE GANCHO PROFESIONAL

Si la captura cumple TODAS estas, el gancho está en categoría "top creator":

- ✓ Test del 1 segundo pasa sin duda
- ✓ E.N.C. con los 3 componentes presentes y balanceados
- ✓ 2-3 gatillos activados claramente
- ✓ Gancho textual con estructura de copywriting identificable
- ✓ Forma Visual ejecutada con limpieza
- ✓ Cero errores fatales

Esta combinación garantiza retención del primer segundo y aumenta probabilidad de viralización.
