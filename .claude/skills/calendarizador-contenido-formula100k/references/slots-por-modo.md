# Slots por Modo · Lunes-Domingo

Tabla de referencia para asignar tipo de slot (Viral/Valor/Venta) y formato sugerido por día, según el propósito del calendario.

> Estos formatos son **sugerencias base**. Si una idea/guion del usuario calza mejor con otro formato del catálogo respetando el tipo del slot, sustituirlo.

## REGLAS DE INTERCAMBIO

Si el contenido del usuario no encaja con el formato sugerido del slot, se puede **sustituir el formato manteniendo el tipo del slot**. Por ejemplo:

- Slot Lunes Crecimiento (Valor) → puede ser Pizarra (#19) **o** Versus (#12) **o** Niveles (#21) **o** cualquier otro formato del Grupo B/C que sea de tipo Valor.
- Slot Martes Crecimiento (Viral) → puede ser POV (#3) **o** Sketch (#7) **o** Cinemático (#2) **o** cualquier otro formato del Grupo A.

**Nunca cambiar el tipo del slot** (ej: poner una pieza de venta en un día asignado a viral). Si la pieza no encaja en ningún slot del tipo correcto, mover de día o pedir reemplazo al usuario.
