## REGLA DE MATCH

Para asignar un formato a una idea/guion del usuario:

1. **Detectar el tipo del slot del día** (Viral / Valor / Venta) usando `slots-por-modo.md`
2. **Filtrar formatos del grupo correcto:**
   - Slot Viral → Grupo A (formatos #1-9)
   - Slot Valor → Grupo B (formatos #10-24) o Grupo C educativo (#25, #28, #30, #39, #40)
   - Slot Venta → Grupo C (formatos #25-34, principalmente #32, #33, #34, #25, #30)
3. **Dentro del grupo, elegir el que mejor encaja con el contenido:**
   - ¿Es testimonio? → #32
   - ¿Compara dos cosas? → #12 (Versus) o #40
   - ¿Explica un proceso? → #19 (Pizarra) o #25 (Tutorial)
   - ¿Cuenta una historia? → #1 o #11
   - ¿Rompe un mito? → #23
   - ¿Demuestra un producto? → #33

Si una idea no encaja en ningún formato del tipo del slot, **mover de día** o pedirle al usuario un reemplazo. Nunca forzar.
