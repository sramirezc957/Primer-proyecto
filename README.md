# Primer-proyecto
Repo de prueba de claude code

## ¿Qué es este proyecto?

Este es un repositorio de prueba utilizado para experimentar con Claude Code, el asistente de programación en la línea de comandos de Anthropic. Su propósito es servir como entorno de práctica para probar flujos de trabajo con Claude Code, como la creación y edición de archivos, la gestión de ramas y commits en Git, y la automatización de tareas de desarrollo.
